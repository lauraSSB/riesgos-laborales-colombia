# Riesgos Laborales Colombia

Fuentes de datos abiertos usadas para construir una vista minable de riesgos laborales en Colombia:

1. **DIVIPOLA_Codigos_municipios.csv** — Códigos y nombres oficiales de departamento/municipio (DANE).
2. **Estadisticas_Riesgos_Laborales_Positiva_2026.csv** — Estadísticas mensuales de accidentalidad, muertes, pensiones de invalidez e incapacidades por ARL, municipio y actividad económica (Positiva, datos.gov.co).
3. **Catalogo_actividades_economicas.csv** — Catálogo de códigos CIIU de actividad económica.

Fuente: [datos.gov.co](https://www.datos.gov.co)
